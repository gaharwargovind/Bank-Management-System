🏦 Python Bank Management System

A CLI-based Bank Management System developed in Python to practice Object-Oriented Programming (OOP) and build a real-world banking application.

⸻

✨ Features

* 👤 Create Savings & Current accounts
* 🔐 Secure PIN authentication using SHA-256 hashing
* 💰 Deposit & Withdraw money
* 🔄 Transfer funds between accounts
* 📜 Transaction history with timestamps
* 📈 Interest calculation for Savings accounts
* 💳 Overdraft support for Current accounts
* 💾 JSON-based data storage
* ⚠️ Custom exception handling

⸻

🛠️ Tech Stack

* 🐍 Python 3
* 📂 JSON
* 🔑 Hashlib (SHA-256)
* 📅 Datetime
* 🧩 Object-Oriented Programming (OOP)
